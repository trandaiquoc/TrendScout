## Quota and cache states

| Situation | UI treatment | Do not imply |
| --- | --- | --- |
| Known total and remaining | Exact count, reset time, scope and timestamp; percentage only with known denominator | A plan default is the account allocation |
| Known daily quota | Remaining today and timezone/reset boundary | Provider quota equals local admission limit |
| Rate-limited; total unknown | Say rate-limited and total quota unreported; retry time if returned | Invented quota/percentage bar |
| Provider publishes no quota | Quota not published/unknown; link policy/docs | Zero or unlimited quota |
| Exhausted | Follow admission policy; show prior saved data with original timestamps | Repeated calls will succeed; cached data is live |
| Temporary error | Keep prior result with original observation/fetch time and stale/error label | Old result is a new success |
| Cache-only current | Loaded from saved data with source time and cache age | Live retrieval |
| Stale cache | Age and last success; refresh only if admitted | Hidden age or reset fetched_at |
| No cache | Unavailable/empty state and recovery step | Fabricated zero rows |
| Partial/truncated | Returned/retained count, cap and reason | Full provider coverage |

Local fetch admission is an application control, not provider quota; keep the labels separate.

## Category taxonomy proposal

Start with Search & trends; Social networks; Video & creators; Communities/forums; News/media/open data; E-commerce/marketplaces; Websites/content; Entertainment & interests; Other. A platform may expose multiple surfaces. Use stable IDs and parent/provider IDs; source type and metric remain separate.

## Coverage conclusion and open decisions

- The inventory has exactly **81 platform candidates**. Four preceding legend rows in its Markdown make 85 pipe-table rows overall; they are code definitions, not platforms.
- The repository has four runtime capability descriptors, not 81. One has local historical LIVE verification; three are offline-tested only. The other candidates remain research entries.
- Current Sources UI exposes no account-specific quota remaining, reset, provider billing, or per-source live-cache age. Do not add quota bars without authorized, sourced values.
- Keep restricted/partner-scoped/unverified candidates in a future library with blockers; do not silently treat them as supported. Review authorization, commercial rights, geography, metric, quota/cost, retention/deletion, attribution, privacy and freshness before integration.
- Provider facts and policy in the source inventory were checked 2026-11-11; revalidate before implementation. This G0 audit did not query provider accounts.
