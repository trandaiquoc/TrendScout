Data, hosting and access

TrendScout does not require an account or Google OAuth. If an operator enables YouTube using server-side settings, a user-triggered Fetch may send bounded search queries through YouTube Data API v3 and receive public video IDs, titles, descriptions, channel identifiers and names, publication times and result positions. The API key stays on the server. Browser users cannot change quota rules. The regionCode=US filter indicates regional relevance or availability; it does not establish where a creator or viewer lives. YouTube source evidence is kept separate from Google and Bing results.

The source cache is configured for a maximum seven-day lifetime and distinguishes original observation time from cached delivery. The application also returns fetched evidence to the browser for display. Hosting project settings, recipients, log contents, backup handling and retention outside this application cache have not been fully verified. Keep public YouTube access disabled until those operational details and this draft are reviewed.
